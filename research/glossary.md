# Glossary (materials science → plain English)

| Term | Meaning |
|------|---------|
| **X-ray CT / XCT / X-CT** | Many X-ray pictures from different angles, combined into a 3D volume. Same idea as a hospital CT scan, but for objects. |
| **Voxel** | A 3D pixel. |
| **Void / pore / defect** | A tiny empty hole inside the metal. It shows up dark in CT. |
| **Ferritic steel** | A common type of steel (iron with a body-centred-cubic crystal structure). Used in pipes, pressure vessels and structures. |
| **Tensile test** | Pulling a bar until it stretches or breaks. |
| **Strain / local strain** | How much a region has stretched, relative to its original length (e.g. 0.3 = 30%). |
| **Fatigue test** | Loading and unloading a bar many times. Metal can break under repeated loads far below its one-time breaking load. |
| **HCF / LCF / ULCF** | High-, low- and ultra-low-cycle fatigue. HCF means many cycles at lower load; ULCF means very few cycles at very high load. |
| **Fracture progress** | How far along a sample is toward breaking (0 = new, 1 = broken). |
| **R-ratio** | Minimum load divided by maximum load in a fatigue cycle. R = 0.1 means the load swings between 10% and 100%. |
| **Ductile fracture** | Breaking by voids *nucleating* (appearing), *growing*, then *coalescing* (joining up) into a crack. |
| **Persistent homology (PH)** | A topology method that summarises the "shape" of the holes and clusters in data across scales. It outputs a *persistence diagram* (a set of birth/death points). |
| **Additive manufacturing (AM)** | Metal 3D printing. Known for pores such as "lack-of-fusion" (unmelted gaps) and "keyhole" (gas bubbles). |
| **Radiography** | A single 2D X-ray image (no 3D reconstruction). |
| **Neutron imaging** | Like X-ray imaging but with neutrons. It sees light elements such as hydrogen inside metals, which X-rays cannot. |
| **Sparse-view CT** | CT reconstructed from fewer angles. Faster, but noisier. |
| **Conformal prediction** | A statistical wrapper around any model that turns its predictions into intervals with a *guaranteed* coverage rate. |
